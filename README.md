## Featured Project

### ERP Blockchain System

A blockchain-integrated ERP system designed to improve **transaction integrity, policy-based approval, blockchain anchoring, and multi-organization auditability**.

The system combines a traditional ERP backend with **Hyperledger Fabric** to provide tamper-evident transaction verification and an auditable transaction lifecycle.

**Main Features:**

- Policy-based transaction approval
- Automatic transaction approval
- Manager approval workflow
- Multi-organization approval
- Hyperledger Fabric blockchain anchoring
- SHA-256 transaction hashing
- Integrity verification
- Transaction audit timeline
- PostgreSQL transaction management
- Approval and audit logging
- Role-based access control
- Notification system
- Enterprise transaction monitoring dashboard

**Main Tech Stack:**

Node.js · Express.js · PostgreSQL · Sequelize · Hyperledger Fabric · Docker · JavaScript

**Repository:**  
https://github.com/tanirahman-source/erp-blockchain-system
