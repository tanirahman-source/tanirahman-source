## Featured Project

### ERP Blockchain System

A blockchain-integrated ERP transaction management and auditability system
built using Hyperledger Fabric.

The system is designed to provide secure transaction processing,
policy-based approval, blockchain anchoring, integrity verification,
and multi-organization auditability.

### Key Features

- Role-Based Access Control (RBAC)
- Multi-Organization architecture
- Policy-based transaction approval
- Automatic transaction approval
- Manager approval workflow
- Multi-organization approval
- Hyperledger Fabric transaction anchoring
- SHA-256 transaction hashing
- Blockchain-based integrity verification
- Audit logging
- Approval notifications
- ERP dashboard
- Transaction statistics
- Dynamic transaction timeline
- PostgreSQL database
- Authenticated API access

### Technologies

`Node.js` `Express.js` `JavaScript` `HTML` `CSS`
`PostgreSQL` `Sequelize` `Hyperledger Fabric`
`Docker` `Linux` `Git` `GitHub`
