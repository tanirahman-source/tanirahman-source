## Featured Project

### ERP Blockchain System

A blockchain-integrated Enterprise Resource Planning system focused on
transaction integrity, policy-based approval, multi-organization
auditability, and secure transaction verification.

The system combines traditional ERP transaction management with
Hyperledger Fabric to provide an immutable blockchain-based audit layer.

### Main Features

- Policy-based transaction approval
- Automatic approval for eligible transactions
- Manager approval workflow
- Multi-organization approval
- Role-based access control
- User authentication and authorization
- Organization-level access control
- Hyperledger Fabric blockchain anchoring
- SHA-256 transaction integrity verification
- PostgreSQL transaction management
- Approval management
- Approval notifications
- Transaction audit logs
- Dynamic transaction timeline
- Blockchain-based auditability
- Integrity verification between ERP data and blockchain records

### Policy Engine

The system uses different approval levels based on transaction amount:

- Automatic approval for low-value transactions
- Manager approval for medium-value transactions
- Manager and Auditor approval for high-value transactions

### Technology Stack

Node.js · Express.js · PostgreSQL · Sequelize · Hyperledger Fabric · Docker · JavaScript
